# Online Retail Sales Analysis & Customer Insights

## Project Overview
This project performs Exploratory Data Analysis (EDA) on an Online Retail dataset to understand sales performance, customer behavior, and business insights.

## Dataset
Online Retail transaction dataset.

## Objectives
- Analyze sales and revenue
- Identify top-selling products
- Analyze country-wise sales
- Understand customer purchasing behavior
- Find useful business insights

## Data Cleaning
- Handled missing values
- Removed duplicate records
- Removed invalid transactions
- Checked Quantity and Unit Price

## Exploratory Data Analysis
- Quantity analysis
- Unit Price analysis
- Revenue analysis
- Country-wise analysis
- Product-wise analysis
- Customer analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Conclusion
The analysis provides useful insights into sales performance, products, countries, and customer purchasing patterns.
